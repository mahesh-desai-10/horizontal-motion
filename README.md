
# Horizontal Motion

Reusable scroll-driven text reveal animations for React.

## Installation

```bash
npm install horizontal-motion framer-motion
```

## Usage

```jsx
import { ScrollReveal } from "horizontal-motion";
import "horizontal-motion/style.css";

export default function App() {
  return (
    <ScrollReveal
      text="Create beautiful scroll-driven animations."
      color="#f5f5f5"
    />
  );
}
```
